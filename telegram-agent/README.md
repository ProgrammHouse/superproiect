# Telegram-агент на Claude

Бот, который сам отвечает на сообщения в Telegram с помощью Claude.

Работает в двух режимах:

1. **Обычный бот.** Отвечает всем, кто пишет вашему боту.
2. **От вашего имени (Telegram для бизнеса).** Бот подключается к вашему личному аккаунту и отвечает на личные сообщения вместо вас. Для этого нужен **Telegram Premium**.

Когда вы сами пишете в чат, бот замечает это и замолкает в этом чате на 30 минут, чтобы не перебивать живой разговор.

## Что понадобится

- Компьютер или сервер, на котором бот будет работать постоянно (бот отвечает, только пока запущен)
- Python 3.10 или новее
- Токен бота от [@BotFather](https://t.me/BotFather)
- Ключ Claude API: [platform.claude.com/settings/keys](https://platform.claude.com/settings/keys). Запросы к Claude платные, баланс пополняется там же.

## Запуск

```bash
cd telegram-agent
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # Windows: copy .env.example .env
```

Откройте файл `.env` и впишите туда `TELEGRAM_BOT_TOKEN` и `ANTHROPIC_API_KEY`. Затем запустите:

```bash
python bot.py
```

Напишите своему боту в Telegram, и он ответит.

## Как подключить бота к своему аккаунту

1. В @BotFather: `/mybots` → ваш бот → **Bot Settings** → **Business Mode** → **Turn on**.
2. В Telegram: **Настройки** → **Telegram для бизнеса** → **Чат-боты**.
3. Введите имя своего бота (например, `@my_helper_bot`).
4. Выберите, в каких чатах ему отвечать, и разрешите ему **отвечать на сообщения**.

Теперь бот отвечает на входящие личные сообщения от вашего имени.

## Как настроить ответы

Откройте `persona.txt` и опишите, кто вы и как бот должен отвечать. Чем подробнее вы его заполните, тем точнее будут ответы. После правки перезапустите бота.

Остальные настройки лежат в `.env`:

| Настройка | Что делает |
|---|---|
| `CLAUDE_EFFORT` | `low` — быстрее и дешевле, `medium` — по умолчанию, `high` — вдумчивее |
| `HISTORY_LIMIT` | сколько последних сообщений чата бот помнит (по умолчанию 30) |
| `OWNER_TAKEOVER_MINUTES` | сколько минут бот молчит после вашего сообщения в чате (по умолчанию 30) |

## Важно знать

- **Бот отвечает, только пока запущен.** Если закрыть терминал или выключить компьютер, он замолчит. Чтобы бот работал круглосуточно, запускайте его на сервере (VPS).
- **История хранится в памяти.** После перезапуска бот забывает прошлые разговоры.
- **Бот понимает только текст.** На голосовые, фото и файлы он просит написать текстом.
- **Если модель отказывается отвечать** по соображениям безопасности, запрос автоматически повторяется на запасной модели. Если отказалась и она, бот просто промолчит.
- Команда `/reset` в чате с ботом очищает историю разговора.
- Файл `.env` содержит ваши ключи. Никому его не отправляйте и не загружайте на GitHub (он уже добавлен в `.gitignore`).
